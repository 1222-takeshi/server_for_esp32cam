# プロジェクトの実行

現在、このプロジェクトは主に単一のESP32-CAMのようなデバイスから画像を受信して表示するサーバーを提供します。「将来の開発 / ロードマップ」セクションで説明されている複数カメラ管理、MLベースの物体認識、リモートI/O制御の機能は計画中の機能強化です。

### 1. サーバーの実行:

*   ターミナルで `script` フォルダを含むディレクトリに移動します。
*   仮想環境を作成した場合は、それがアクティブになっていることを確認してください。
    ```bash
    # Windowsの場合
    # venv\Scripts\activate
    # macOS/Linuxの場合
    # source venv/bin/activate
    ```
*   Flaskサーバーを実行します:
    ```bash
    python script/server.py
    ```
*   デフォルトでは、サーバーは `http://0.0.0.0:8080/` で起動します。これは、ネットワーク上の任意のIPアドレスからポート8080でアクセス可能であることを意味します。
*   ターミナルにサーバーが実行中であることを示す出力が表示されます (類似の形式):
    ```
     * Serving Flask app 'server'
     * Debug mode: off
     * Running on all addresses (0.0.0.0)
     * Running on http://127.0.0.1:8080
     * Running on http://<your_local_ip>:8080
    Press CTRL+C to quit
    ```
    同じネットワーク上の別のデバイス (ESP32-CAMなど) からサーバーにアクセスする場合は、`<your_local_ip>` をメモしておきます。

### 2. クライアントの設定と実行 (例: ESP32-CAM):

*   クライアントデバイス (例: ESP32-CAM) が以下のようにプログラムされていることを確認してください:
    *   サーバーと同じWi-Fiネットワークに接続する。
    *   画像をキャプチャする。
    *   これらの画像をHTTP POSTリクエストとしてサーバーの `/upload` エンドポイントに送信する。URLは `http://<server_ip_address>:8080/upload` となり、`<server_ip_address>` は `server.py` を実行しているマシンのIPアドレスです。
*   ESP32-CAMまたは他のクライアントデバイスの電源を入れて実行します。

### 3. アップロードされた画像へのアクセス:

*   クライアントから画像がアップロードされると、Webブラウザで次のURLに移動して表示できます:
    `http://<server_ip_address>:8080/files`
*   このページには、正常にアップロードされたすべての画像ファイルが一覧表示されます。ファイル名をクリックすると画像が表示されます。
*   アップロードされた画像は、サーバーのプロジェクトルートフォルダ内の `uploads` ディレクトリに保存されます。

### 将来の機能強化 (マルチカメラ、ML、I/O制御):

「将来の開発 / ロードマップ」で概説されている機能 (マルチカメラフィード、ML処理、I/O制御など) が実装されると:
*   サーバー (`server.py`) が大幅に強化されるか、新しいコンポーネント/スクリプトが導入される可能性があります。
*   クライアントサイド (ESP32) ファームウェアは、新しい機能をサポートするために対応する更新が必要になります (例: カメラIDの送信、制御コマンドの受信)。
*   これらの高度な機能の設定と実行に関する詳細な手順は、このREADMEの各セクションまたは新しい専用ガイドに追加されます。
