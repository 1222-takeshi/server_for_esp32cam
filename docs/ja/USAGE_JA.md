# 使用方法ガイド

このガイドでは、ESP32マルチカメラシステムのサーバーを実行し、クライアントを設定し、現在の機能を使用する方法について説明します。マルチカメラ管理、MLベースの物体認識、リモートI/O制御などの高度な機能は、[プロジェクトロードマップ](ROADMAP_JA.md)に詳述されている通り、計画中の機能強化であることに注意してください。

## プロジェクトの実行

現在、このプロジェクトは主に単一のESP32-CAMのようなデバイスから画像を受信して表示するサーバーを提供します。

### 1. サーバーの実行:

*   ターミナルで `script` フォルダを含むディレクトリに移動します。
*   仮想環境を作成した場合（[セットアップガイド](SETUP_JA.md)で推奨）、それがアクティブになっていることを確認してください:
    ```bash
    # Windowsの場合
    # venv\Scripts\activate
    # macOS/Linuxの場合
    # source venv/bin/activate
    ```
*   Flaskサーバーを実行します:
    ```bash
    python script/server.py
    ```
*   デフォルトでは、サーバーは `http://0.0.0.0:8080/` で起動します。これは、ネットワーク上の任意のIPアドレスからポート8080でアクセス可能であることを意味します。
*   ターミナルにサーバーが実行中であることを示す出力が表示されます (類似の形式):
    ```
     * Serving Flask app 'server'
     * Debug mode: off
     * Running on all addresses (0.0.0.0)
     * Running on http://127.0.0.1:8080
     * Running on http://<your_local_ip>:8080
    Press CTRL+C to quit
    ```
    同じネットワーク上の別のデバイス (ESP32-CAMなど) からサーバーにアクセスする場合は、`<your_local_ip>` をメモしておきます。

### 2. クライアントの設定と実行 (例: ESP32-CAM):

*   クライアントデバイス (例: ESP32-CAM) が以下のようにプログラムされていることを確認してください:
    *   サーバーと同じWi-Fiネットワークに接続する。
    *   画像をキャプチャする。
    *   これらの画像をHTTP POSTリクエストとしてサーバーの `/upload` エンドポイントに送信する。URLは `http://<server_ip_address>:8080/upload` となり、`<server_ip_address>` は `server.py` を実行しているマシンのIPアドレスです。 (ESP32-CAMのセットアップ詳細は[セットアップガイド](SETUP_JA.md)を参照してください)。
*   ESP32-CAMまたは他のクライアントデバイスの電源を入れて実行します。

### 3. アップロードされた画像へのアクセス:

*   クライアントから画像がアップロードされると、Webブラウザで次のURLに移動して表示できます:
    `http://<server_ip_address>:8080/files`
*   このページには、正常にアップロードされたすべての画像ファイルが一覧表示されます。ファイル名をクリックすると画像が表示されます。
*   アップロードされた画像は、サーバーのプロジェクトルートフォルダ内の `uploads` ディレクトリに保存されます。

### 将来の機能強化 (マルチカメラ、ML、I/O制御):

[プロジェクトロードマップ](ROADMAP_JA.md)で概説されている機能 (マルチカメラフィード、ML処理、I/O制御など) が実装されると:
*   サーバー (`server.py`) が大幅に強化されるか、新しいコンポーネント/スクリプトが導入される可能性があります。
*   クライアントサイド (ESP32) ファームウェアは、新しい機能をサポートするために対応する更新が必要になります (例: カメラIDの送信、制御コマンドの受信)。
*   これらの高度な機能の設定と実行に関する詳細な手順は、このドキュメントまたは新しい専用ガイドに追加されます。

## 詳細な使用方法 (現在の機能)

Webサーバーは以下の機能を提供します:

### サーバーエンドポイント:

*   **`GET /`**
    *   **説明:** メインHTMLページ (`templates/index.html`) を表示します。
    *   **使用方法:** Webブラウザで `http://<server_ip>:8080/` を開きます。
    *   **レスポンス:** アップロードされたファイルを表示するためのリンクがあるHTMLページ。

*   **`POST /upload`**
    *   **説明:** 画像ファイルをアップロードするためのエンドポイント。サーバーはリクエストボディに生の画像データを期待します。
    *   **使用方法 (プログラム的、例: ESP32-CAMまたはスクリプトから):**
        画像データをボディに入れてHTTP POSTリクエストを送信します。
        *   **メソッド:** `POST`
        *   **URL:** `http://<server_ip>:8080/upload`
        *   **ヘッダー (例):** `Content-Type: image/jpeg` (または画像形式に応じて `image/png` など)
        *   **ボディ:** 画像の生のバイナリデータ。
    *   **レスポンス (成功時):**
        *   **ステータスコード:** `200 OK`
        *   **ボディ (JSON):** `{"message": "File uploaded successfully"}`
    *   **レスポンス (失敗時):**
        *   **ステータスコード:** `400 Bad Request` (例: データなし) または `500 Internal Server Error`。
        *   **ボディ (JSON):** `{"message": "File upload failed", "error": "<error_details>"}`
    *   **注意:** アップロードされたファイルは、サーバーの `uploads/` ディレクトリに `image_<timestamp>.jpg` のようなファイル名で保存されます。

*   **`GET /files`**
    *   **説明:** `uploads/` ディレクトリ内のすべてのファイルを一覧表示するHTMLページ (`templates/files.html`) を表示します。
    *   **使用方法:** Webブラウザで `http://<server_ip>:8080/files` を開きます。
    *   **レスポンス:** クリック可能なファイル名のリストがあるHTMLページ。

*   **`GET /files/<filename>`**
    *   **説明:** `uploads/` ディレクトリから特定のファイルを配信します。
    *   **使用方法:**
        *   通常は `/files` ページ上のリンクをクリックしてアクセスします。
        *   または、Webブラウザで直接 `http://<server_ip>:8080/files/<filename_to_view>` を介してアクセスします。
    *   **レスポンス:** 要求された画像ファイル。

### Webインターフェース:

1.  **メインページ (`/`):**
    *   「アップロードされたファイルを表示」というリンクがある開始点を提供します。

2.  **アップロードされたファイルページ (`/files`):**
    *   サーバーに正常にアップロードされたすべての画像を一覧表示します。
    *   各ファイル名はリンクになっており、クリックすると対応する画像が表示されます。

### サンプルワークフロー (ESP32-CAMからサーバーへ):

1.  **ESP32-CAM:** 画像をキャプチャします。
2.  **ESP32-CAM:** Wi-Fiに接続します。
3.  **ESP32-CAM:** HTTP POSTリクエストを介して画像データを `http://<server_ip>:8080/upload` に送信します。
4.  **サーバー:** データを受信し、`uploads/image_<timestamp>.jpg` として保存し、成功メッセージで応答します。
5.  **ユーザー:** ブラウザで `http://<server_ip>:8080/files` を開き、アップロードされた画像のリストを表示します。
6.  **ユーザー:** 画像ファイル名をクリックして表示します。
