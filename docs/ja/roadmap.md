# 将来の開発 / ロードマップ

このプロジェクトは現在、次の実用的な最初のマイルストーンにあります:

* 単一の ESP32-CAM
* JPEG スナップショット upload
* 中央サーバー保存
* ブラウザからの閲覧

今後の拡張は、このスナップショット優先の本線を崩さない形で進めます。

### 1. 単一カメラスナップショット経路の安定化

*   upload 検証と保存挙動を強化する
*   ブラウザ UI を単純かつ確実に保つ
*   deep sleep 前提の低電力スナップショット運用を改善する

### 2. 保存先 backend の柔軟化

*   ESP32-CAM からの upload は常に中央サーバー API に送る
*   サーバー側で次の保存先を切り替えられるようにする
    * ローカルディスク
    * NAS
    * Google Drive

### 3. 複数カメラ識別の導入

*   単一カメラ経路が安定してから camera ID を追加する
*   保存資産をカメラ単位に整理する
*   UI 上で画像ソースを見分けやすくする

### 4. 短い動画クリップの評価

*   連続動画は最初のデフォルトにしない
*   スナップショットだけでは足りない場合に短いクリップ upload を検討する
*   低電力運用を引き続き設計制約とする

### 5. 高度機能は後回しにする

*   ML 処理
*   アラート / 通知
*   リモート I/O 制御
*   より高度な自動化パイプライン

これらは、スナップショットと保存経路が安定した後に追加します。
