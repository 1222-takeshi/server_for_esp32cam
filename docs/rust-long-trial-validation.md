# Pi長時間試験の初回結果（2026-10-25 UTC）

Issue #573で60秒から10分へ計測を延長しました。マスク修正FW（PR #581）と
有限計測延長（PR #582）を使い、推論はPi 4上で行いました。
[条件と証拠SHA](rust-long-trial-validation.json)を機械可読形式で保全しています。

## 結果

600秒指定の試験は **`mode_degraded / frames_expired` で中断**しました。
native監視記録は31回、受信78件のうち75件を推論・公開し、3件を推論前に除外しました。
worker側の破棄・推論失敗・証拠欠落・receiver overwrite/busy・ACK拒否は0件です。
停止直前の公開はsequence78、続く79〜81の受信を記録しています。
3件の除外は既存rawに理由がないため、順序・世代・時計・到着ageのどのgateかは未確定です。
500msの結果更新期限を緩めずholdへ移りました。**10分未達のため1時間試験は実行していません。**

監視時の最大温度56.965℃、throttleは全記録0、native peak RSS48.906MiBでした。
これだけで無線遅延や時計の寄与は断定できません。過去の60秒成功・失敗記録も保持し、
今回の失敗を除外して安定5Hz・速度改善・認識精度維持の実機受入とはしていません。
モデル/ORT/FP32・320・threads3・score0.5/NMS0.7、QVGA/JPEG12、165ms予約・500ms保護は維持。
ライブ画像のGT精度・10Hz・常設Rust移行・物理モータは評価していません。

## 復旧と記録量

候補OTAと元FWの2段階復旧OTAは、異なる予約port47199/53167/58661で各初回成功しました。
元FW `feed55ed...`、元Python `613d293`、元unit、eco active/ACK/hold/readyへ復旧し、
旧guard有効・試験guard無効・cleanup完了を確認しています。runnerは失敗をexit1として記録しました。
選択した数値raw16ファイルは計41,711bytes、native reportは17,949bytesです。
JPEG・設定・鍵・大きなバイナリはGitへ追加せず、元rawとmanifestはprivate領域に0400で保全しました。

## 次の切分け

受信の事前除外に、最後32件だけの数値診断を追加します。順序/モード/時計証拠なし/age超過を分け、
boot・世代・capture/send/receive時刻・age区間と、その時点の時計交換を最大8件保持します。
age区間はi128の整数を十進文字列にして桁落ちを避けます。画像・API key・nonceは記録しません。
診断は除外後だけ実行し、採用判定・時計の期限/交差・推論条件を変えません。
原因の再現と切分け後、同じ全10秒窓50件・age/gap500msで10分→1時間へ進めます。
