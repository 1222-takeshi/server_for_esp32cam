# ESP32マルチカメラシステム (ML・I/O制御対応ポテンシャル)

このプロジェクトは、複数のESP32カメラからの画像を中央のWebサーバーに表示できる多機能なシステムの構築を目指しています。画像表示に加えて、機械学習ベースの物体認識を統合し、ESP32カメラに接続されたモーターやその他のI/Oデバイスの制御も可能にすることを構想しています。

現在、サーバーは単一ソースからの画像の受信と表示をサポートしています。将来の開発では、これを複数のカメラフィードに対応できるように拡張し、ML処理パイプラインを実装し、I/O制御のための通信チャネルを確立することに焦点を当てます。

**コア機能 (現状および計画中):**

*   **画像集約:**
    *   ESP32-CAMデバイスからアップロードされた画像を受信・保存します (現在は単一、複数対応を計画中)。
    *   アップロードされた画像を一覧表示・閲覧するためのWebインターフェースを提供します。
*   **複数カメラサポート (計画中):**
    *   様々なESP32カメラからのフィードを識別・管理するメカニズム。
    *   複数のカメラビューを表示するためのユーザーインターフェースの強化。
*   **機械学習統合 (計画中):**
    *   物体検出などのタスクのために、OpenCVや他のMLフレームワークを使用したサーバーサイドでの画像・ストリーム処理。
    *   カメラフィードと並べて認識結果を表示。
*   **リモートI/O制御 (計画中):**
    *   モーターやその他の周辺機器を作動させるために、サーバーからESP32デバイスへ制御信号を送信するインターフェース。

## 謝辞

*   このプロジェクトは、軽量なWSGI Webアプリケーションフレームワークである[Flask](https://flask.palletsprojects.com/)を使用しています。
*   ESP32-CAMや画像サーバーの操作に関するインスピレーションは、エレクトロニクスやIoT愛好家の活気あるコミュニティから得られることがよくあります。(特定のチュートリアル、記事、または個人に謝意を表したい場合は、ここに追加してください！)
*   Espressifによる[ESP32カメラドライバ](https://github.com/espressif/esp32-camera)は、ESP32-CAMベースのプロジェクトにとって基本的なコンポーネントです。
